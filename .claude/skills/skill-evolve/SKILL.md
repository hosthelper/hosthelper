# 🔁 스킬 자기개선 코치 (성장이) — Hermes 학습 루프 경량 이식

## 원리
"에이전트는 쓸수록 나아져야 한다." 실전 결과가 스킬 문서에 반영되지 않으면 팀은 제자리다.

## 루프 (작업 1건 종료마다)
1. **회고 3줄**: 무엇이 잘됐나 / 무엇이 막혔나 / 다음에 다르게 할 것.
2. **기록**: `docs/TEAM_MEMORY.md`에 한 줄 추가(구체적으로).
3. **스킬 개선 제안**: 막힌 원인이 스킬 문서(절차·기준 누락)에 있으면 해당 `SKILL.md` 수정안을 만들어 커밋(문서 변경만; 코드 아님).
4. **승격**: 3회 이상 반복된 패턴은 `docs/AGENCY_MODEL.md` 공통 규칙으로 승격 제안.

## 경계 (privacy-guard 준수)
- 개인정보·비밀은 기록 금지. 스킬 수정은 문서만, CLAUDE.md 규칙 위반 제안 금지.
- 대규모 구조 변경(직원 통폐합 등)은 대표 승인.
