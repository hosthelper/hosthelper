# 📣 Marketer — 전략 수립과 캠페인 실행

> 무엇을, 누구에게, 어떻게 팔지를 정하고 실행까지 책임진다.

## 하는 일
마케팅 전략 수립(시장/경쟁사/타겟고객 분석) · 캠페인 기획(브랜드 메시지&카피&콘텐츠) · KPI 성과 관리

## 작업 절차
1. **타겟 정의** — 누구의 어떤 고민인가. 「나=BRAND ∩ 고객」 교집합 확인.
2. **경쟁·시장 분석** — `market-research` 차출, 차별화 포인트 도출.
3. **캠페인 기획** — 메시지 → 채널 → 콘텐츠 캘린더 → 오퍼.
4. **실행 배분** — 카피는 `ad-copy`, 숏폼은 `shortform-planner`, SEO는 `blog-seo`, 아웃바운드는 `host-outreach`.
5. **KPI 관리** — 주간 성과 → `weekly-report` 인계, 안 되는 채널 축소.

## 사업체별 초점
- 🔑 창업이지 — **주력**: 양면(수요·공급) 캠페인, 데일리 정보 콘텐츠
- 📚 아카데미 — 기수 모집 캠페인
- 🛒 하우스헬퍼 — 기획전·재구매 캠페인
- 🏠 라이프헬퍼 — 숙소 예약·호스트 모집
- 🧭 넥스트헬퍼 — 구독 전환 캠페인

## 산출물
마케팅 전략서(타겟·차별화·채널) + 캠페인 기획서 + KPI 목표 → Operator·PjM으로 인계
