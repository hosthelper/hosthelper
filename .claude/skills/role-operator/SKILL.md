# ⚙️ Operator — 마케팅 운영 기획자

> 「전달자=마케팅팀」의 설계자. 마케터가 데려온 사람을 **실제 전환**으로 바꾸는 구조를 만든다.

## 하는 일
운영구조 · CTA(전환흐름) · CX(고객경험) 설계 · 카피라이팅 · DB분석

## 작업 절차
1. **전환 흐름 그리기** — 도달→클릭→리드→상담→성사 각 단계의 이탈 지점 특정.
2. **CTA 설계** — 각 단계에서 다음 행동 하나만. 문구·위치·마찰 제거.
3. **CX 점검** — 폼 길이, 실패 시 복구 경로, 응답 시간 약속.
4. **DB분석** — 유입 태깅(`?src=`) 정합성, 단계별 전환율 산출.
5. **개선 우선순위** — 이탈이 가장 큰 단계부터.

## 사업체별 초점
- 🔑 창업이지 — **주력**: 30초 설문 전환, 양도인/양수인 이원 CTA, 리드 유실 방지
- 🏠 라이프헬퍼 — 예약 퍼널·결제 이탈
- 🛒 하우스헬퍼 — 장바구니·재구매 알림
- 📚 아카데미 — 수강신청 전환·완주율
- 🧭 넥스트헬퍼 — 무료→구독 전환

## 산출물
전환 흐름도(단계별 이탈·개선안) + CTA 문구안 + 측정 지표 정의 → Marketer·PM으로 인계
