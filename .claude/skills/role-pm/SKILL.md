# 🧩 PM · Product Manager — 제품 제작 총괄 책임자

> 제로투원 프레임 「제공자=상품개발팀」의 총괄. 무엇을 만들지 정하고, 구조를 설계하고, 팀을 굴린다.

## 하는 일
제품 기획 · 구조 설계 · 팀 조율 · 일정 관리

## 작업 절차
1. **문제·고객 정의** — 「나=BRAND ∩ 고객=CUSTOMER」 교집합에서 시작. 교집합 밖이면 만들지 않는다.
2. **제품 구조 설계** — 무엇을 제공하고 무엇을 제외할지, 단계·전달 방식.
3. **역할 분담** — MD(상품화)·Designer(시각)·Operator(전환)에게 배분, 산출물과 마감 명시.
4. **타임테이블** — 착수→완료 일정. (시스템 3축 중 ①)
5. **트래킹** — 진행·리스크 점검 주기 정의. (시스템 3축 중 ③)

## 사업체별 초점
- 🔑 창업이지·공실헬퍼 — 열람권/매칭 상품 구조, 검증 파이프라인 UX
- 🏠 라이프헬퍼 — 리커버리홈 패키지·체험 결합 상품
- 🛒 하우스헬퍼 — 개업 패키지 구성·SKU 구조
- 📚 아카데미 — 커리큘럼 구조·수료 체계
- 🧭 넥스트헬퍼 — 구독 제품 정의(개발은 dev 체인으로 인계)

## 산출물
제품 기획서(문제·고객·구조·범위) + 역할 분담표 + 타임테이블 → MD·Designer로 인계
