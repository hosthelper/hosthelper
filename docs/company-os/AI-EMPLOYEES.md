# AI 직원 7명 — 헬퍼유니버스

이름으로 부르면 일합니다. 프롬프트를 복사할 필요가 없습니다.

> 그냥 "마케팅팀, 이번 주 주제 뽑아줘"라고 하면 됩니다.

정의 파일은 [`.claude/agents/`](../../.claude/agents/)에 있습니다.
**에이전트는 세션 시작 시 로드됩니다** — 정의를 새로 추가하거나 고쳤다면 새 세션에서 반영됩니다.

## 명단

| 부를 이름 | 부서 | 무엇을 내놓는가 | 도구 |
|---|---|---|---|
| `hu-ceo` | 대표실 | 목표 1문장 · 우선순위 5개 · 부서별 첫 업무와 완료 조건 | 읽기 + Write |
| `hu-marketing` | 마케팅팀 | 주제 3개 · 훅 · 핵심 3개 · 실제 근거 · CTA | 읽기 + 웹검색 |
| `hu-sales` | 영업팀 | 고객 신호 5개 · 첫 DM · 후속 2개 · 상담 질문 3개 | 읽기 |
| `hu-support` | 고객지원팀 | FAQ 10개 · 사람 결정 항목 분리 · 개선 요청 | 읽기 |
| `hu-finance` | 재무팀 | 월별 현금표 · 유지/줄임/확인 · 부족 시점 · 누락값 | 읽기 |
| `hu-build` | 개발팀 | 최소 버전 기능 · 제작 순서 · 테스트 · 실제 구현 | 전체 |
| `hu-ops` | 운영팀 | 자동화 흐름 · 실패 알림 · 오늘 줄일 반복 1개 | 읽기 + Bash(조회) |

## 순서

```
hu-ceo                     ← 매달 1회. 여기서 시작한다
   ↓ assignments 원문 그대로
hu-marketing · hu-build    ← 제작
   ↓
hu-sales                   ← 판매
   ↓ 실제 받은 질문 원문
hu-support                 ← 응대
   ↓ 반복되는 것
hu-ops                     ← 자동화
   ↓
hu-finance → hu-ceo        ← 유지 / 중단 / 확대 결정
```

**앞 팀 결과물을 요약하지 말고 그대로 넘깁니다.** 요약하는 순간 다음 팀이 판단 근거를 잃습니다.

## 이 에이전트들이 아는 것

정의 파일에는 업무 내용을 복사해 두지 않았습니다. 각자 시작할 때 아래를 **읽고** 일합니다. 문서를 고치면 에이전트가 자동으로 따라옵니다.

| 단일 출처 | 담당 |
|---|---|
| `.claude/skills/helper-universe/SKILL.md` | 브랜드 9개 사실관계 · 가드레일 · 계측 경로 |
| `docs/prompts/company-os/NN-*.md` | 부서별 `[입력]/[업무]/[출력]/[규칙]` |
| `docs/AI_COMPANY_OS.md` | 목표 · 인수인계 · 자동화 현황 |
| `uni` 스킬 | 유니 톤 · 계정 ID · 4채널 발행 레시피 |
| 루트 `CLAUDE.md` | 코드 컨벤션 (개발팀) |

## 안 하는 것

- **실제 발행·전송을 하지 않습니다.** 초안까지만 만들고 사람이 검토해 올립니다.
- 확인되지 않은 수치·후기·사례를 만들지 않습니다. 모르면 `확인 불가`.
- 환불·법률·개인정보 판단을 확정하지 않습니다. 사람 결정 항목으로 분리합니다.
- 브랜드별 제약(라이프헬퍼 의료 문구 · 하우스헬퍼 제품 효능 · 헬퍼아카데미 성과 보장 · 넥스트헬퍼 인증마크 · BGN 기부 약속)을 어기지 않습니다.
