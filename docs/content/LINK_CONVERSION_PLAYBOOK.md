# 링크 전환 플레이북 — 관심 링크를 우리 콘텐츠로

> 대표가 관심 있는 링크(기사·SNS·영상·상품 페이지)를 공유하면,
> 우리 사업(호스트헬퍼 · 라이프헬퍼)에 필요한 부분만 전환해서 우리 것으로 반영하는 표준 절차.

## 1. 원칙

1. **아이디어만 차용, 표현은 새로 쓴다.** 원문 문장·이미지·영상은 복사하지 않는다 (저작권).
   출처가 필요한 사실(통계·요금 등)은 출처 표기 후 인용.
2. **전환 기준은 "게스트/호스트가 얻는 것"**. 링크가 멋있어서가 아니라,
   우리 퍼널(협업숙소 예약, 청소 매칭, 리드 확보) 중 어디를 강화하는지로 판단.
3. **하나의 링크 → 하나의 전환 문서.** 전환 결과는 `docs/content/` 아래 주제 문서에 누적.

## 2. 접수 양식 (링크 공유 시 이 형식이면 가장 빠름)

```
링크: <URL>
왜 관심: (한 줄. 예: "외국인 게스트가 한복 입고 찍은 사진이 반응이 좋음")
적용 대상: 라이프헬퍼 게스트 / 호스트 / 협업숙소 / 기타
```

왜 관심·적용 대상이 없어도 진행하되, 전환 문서에 추정 근거를 명시한다.

## 3. 전환 절차

| 단계 | 작업 | 산출 |
|---|---|---|
| ① 분해 | 링크에서 "무엇이 통했는가"를 3줄 이내로 추출 | 인사이트 요약 |
| ② 매핑 | 우리 퍼널 중 어디에 붙는지 결정 (게스트 경험 / 호스트 모집 / 콘텐츠 발행) | 적용 지점 |
| ③ 전환 | 우리 브랜드·톤·타깃(서울 STR, 외국인 게스트 비중 높음)으로 재작성 | 주제 문서 갱신 |
| ④ 실행 | 필요 시 발행물(카드뉴스·포스트·안내문) 초안까지 작성 | 실행 자산 |

## 4. 산출 목적지

- **게스트 체험 콘텐츠** (K-문화 등): `docs/content/<주제>.md` — 예: [`HANBOK_K_CULTURE.md`](HANBOK_K_CULTURE.md)
- **예비창업자 대상 기사**: `apps/changup-site/posts/` (기존 발행 파이프라인)
- **SNS 발행**: 유니(헬퍼유니버스) 채널 워크플로 재사용

## 5. 링크 내용 확인 수단 (2026-08-04 점검)

작업 환경(Claude Code 원격 세션)은 허용 도메인만 통과하는 네트워크 정책이라
인스타그램 직접 접근·우회 리더(Jina/InstaFix류)가 모두 차단됨. 실제 동작 가능한 경로:

| 경로 | 상태 | 비고 |
|---|---|---|
| ① mirr(mirra) MCP 연동 | **승인 대기** — claude.ai 커넥터 설정에서 인증 필요 | 유니 4채널 발행·분석 도구. 승인되면 링크 분석 파이프라인 1순위 |
| ② Make 시나리오 | 준비 필요 — 인스타그램 연결 없음 + 조직 일시정지(Free) | Make 클라우드에서 실행되어 차단 무관. IG 비즈니스 연결(또는 supadata/Apify 키) 추가 + 조직 재개 시 릴 URL→캡션 추출 자동화 가능 |
| ③ Zapier "Instagram for Business" | 부적합 | 자기 계정 인사이트 전용, 타인 공개 릴 조회 불가 |
| ④ 스크린샷/캡션 복붙 | **즉시 가능** | 이미지는 세션에서 바로 판독 가능. ①/② 준비 전 기본 경로 |
