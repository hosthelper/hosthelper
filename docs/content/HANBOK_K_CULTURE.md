# 한복 K-문화 체험 — 협업숙소에 와야 하는 이유

> 라이프헬퍼 플랫폼을 이용하는 게스트에게 한복으로 K-문화를 체험하게 하는 콘텐츠.
> 목적: "이 숙소(협업숙소)에 묵어야 하는 이유"를 체험으로 만든다.
> 상태: 기획 v1 — 대표 공유 링크 수신 시 [플레이북](LINK_CONVERSION_PLAYBOOK.md) 절차로 구체화.

## 1. 핵심 논리 (Why)

- 서울 STR 게스트의 다수는 외국인 관광객이고, 한복 체험은 이미 검증된 K-문화 수요다
  (경복궁·북촌 일대 한복 대여 상권, 한복 착용 시 고궁 무료입장 제도).
- 숙소는 가격·위치로만 비교되면 가격 경쟁으로 끝난다. **"여기 묵으면 한복 체험이 포함/연결된다"**는
  협업숙소만의 예약 이유가 된다.
- 호스트헬퍼 입장에서는 협업숙소 네트워크의 차별화 콘텐츠 = 호스트 영업 무기이기도 하다
  ("우리 플랫폼에 들어오면 게스트 체험 콘텐츠까지 붙습니다").

## 2. 게스트 여정에 붙는 지점

| 여정 단계 | 한복 콘텐츠 |
|---|---|
| 예약 전 | 숙소 소개에 "한복 K-문화 체험 패키지" 뱃지 + 체험 사진. 예약 전환 훅 |
| 체크인 | 웰컴 안내(다국어)에 한복 대여 제휴처·할인 코드·추천 포토 스팟(고궁·한옥길) |
| 체류 중 | 한복 착용 → 고궁 무료입장 팁, 사진 촬영 가이드, 인근 동선 지도 |
| 체크아웃 후 | 게스트 사진(동의 시) 리뷰·SNS 재사용 → 다음 게스트의 예약 이유로 순환 |

## 3. 협업 모델 (운영)

1. **한복 대여점 제휴**: 숙소 인근 대여점과 게스트 할인(예: 10~20%) 제휴.
   숙소는 송객, 대여점은 할인 제공 — 현금 정산 없는 교차 송객이 1차 목표.
2. **숙소 내 비치(선택)**: 셀프 포토용 한복 1~2벌 + 소품. 청소 턴오버 체크리스트에
   "한복 정돈·상태 확인" 항목 추가(호스트헬퍼 체크리스트와 자연 결합).
3. **패키지화(확장)**: 대여+촬영+동선을 묶은 유료 패키지. 정산 구조는 제휴 확정 후 설계.
