# 헬퍼유니버스 브랜드 공식 기준안

업데이트 기준: 2026-09

## 1. 헬퍼유니버스
- 역할: 숙박업 현업자와 예비창업자의 현재 위치를 파악하고 필요한 다음 단계로 연결하는 통합 허브
- 핵심 질문: "나는 지금 숙박업에서 무엇부터 해야 하지?"
- 메인 카피: "숙박업, 지금 어디쯤 와 계신가요?"
- 서브 카피: "예비창업부터 매물, 교육, 세팅, 운영, 고객유치, 협업까지 현재 상황에 맞는 다음 단계를 찾아드립니다."
- 존재미션: 숙박업을 시작하거나 운영하는 사람이 길을 잃지 않도록 한다.
- 브랜드미션: 고객의 현재 상황을 파악하고 가장 필요한 숙박업 서비스와 다음 행동을 연결한다.
- 공식 한 문장: "숙박업의 시작부터 성장까지, 다음 한 걸음을 연결합니다."

## 2. 공실헬퍼
- 브랜드 정의: 기존 호스트와 예비·현직 호스트를 연결하는 숙박 매물 거래 플랫폼
- 핵심 질문: "이 매물로 숙박업을 해도 괜찮을까?"
- 메인 카피: "망하지 않는 숙박사업, 매물 선택부터 다릅니다."
- 설명 카피: "기존 호스트의 숙박 매물과 새로운 숙박사업 기회를 찾는 예비·현직 호스트를 연결합니다."
- 존재미션: 좋은 숙박공간과 새로운 운영자가 만나지 못해 발생하는 공실과 기회손실을 줄인다.
- 브랜드미션: 숙박업 매물과 운영 경험을 연결해 더 투명하고 효율적인 숙박 매물 거래 시장을 만든다.
- 핵심 역할: 숙박 매물 탐색·판단·거래 연결
- 콘텐츠 방향: 숙박업 매물과 사업 판단에 필요한 지식

## 3. 헬퍼아카데미
- 브랜드 정의: 숙박업 지식을 배우고 실제로 실행하는 교육 플랫폼
- 핵심 질문: "숙박업을 어떻게 시작하고 운영해야 하지?"
- 메인 카피: "배우기만 하지 말고, 실행하면서 배우세요."
- 존재미션: 숙박업을 몰라서 시작하지 못하는 사람의 진입장벽을 낮춘다.
- 브랜드미션: 초보자가 숙박업 지식을 배우고 실제 실행과 첫 수익까지 경험하도록 돕는다.
- 핵심 역할: 숙박업 지식 배우기

## 4. 하우스헬퍼
- 브랜드 정의: 숙소 오픈과 운영에 필요한 비품·가구·인테리어를 구성하는 숙소 세팅 플랫폼
- 핵심 질문: "숙소를 열려면 무엇을 어떻게 준비해야 하지?"
- 메인 카피: "숙소 하나 여는 데 필요한 것, 한 번에."
- 존재미션: 숙소를 세팅하면서 발생하는 시간·비용·시행착오를 줄인다.
- 브랜드미션: 숙박업자가 검증한 제품과 구성을 통해 누구나 효율적으로 숙소를 세팅할 수 있게 한다.
- 핵심 역할: 숙소 세팅

## 5. 호스트헬퍼
- 브랜드 정의: 숙소 운영·위탁·수익관리를 담당하는 숙박 운영 플랫폼
- 핵심 질문: "숙소 운영을 어떻게 더 잘하거나 맡길 수 있지?"
- 메인 카피: "숙소 운영을 시스템으로."
- 존재미션: 좋은 숙소가 운영 부족 때문에 공실이 되는 것을 줄인다.
- 브랜드미션: 예약·가격·채널·운영 데이터를 체계적으로 관리해 숙소가 지속적으로 운영될 수 있도록 한다.
- 핵심 역할: 숙소 운영

## 6. 라이프헬퍼
- 브랜드 정의: 10명 이상 외국인 단체 게스트를 위한 단체전용 숙박 플랫폼
- 핵심 질문: "한국에서 우리 단체가 함께 머물 수 있는 숙소는 어디지?"
- 메인 카피: "10명 이상 외국인 단체라면, 숙소 찾는 방법부터 달라야 합니다."
- 설명 카피: "외국인 단체의 인원·지역·예산·방문 목적에 맞는 숙소를 연결합니다."
- 존재미션: 한국을 방문하는 외국인 단체가 숙소 때문에 불편하지 않도록 한다.
- 브랜드미션: 외국인 단체가 인원·목적·예산에 맞는 숙소를 쉽고 안전하게 찾을 수 있는 단체숙박 인프라를 만든다.
- 핵심 역할: 외국인 단체숙박 연결

## 7. 넥스트헬퍼
- 브랜드 정의: 숙박업 종사자와 관련 전문가가 연결되는 협업·상생 네트워크
- 핵심 질문: "숙박업을 하면서 누구와 협업해야 더 성장할 수 있을까?"
- 메인 카피: "좋은 사람에게, 좋은 기회가 흐르게."
- 존재미션: 좋은 사업가와 전문가가 서로 만나지 못해 발생하는 기회손실을 줄인다.
- 브랜드미션: 신뢰할 수 있는 숙박업 관계자들을 연결해 거래·추천·협업이 일어나는 상생 생태계를 만든다.
- 핵심 역할: 숙박업 협업

## 전체 고객 여정
헬퍼유니버스(현재 위치 파악)
→ 공실헬퍼(숙박 매물 탐색)
→ 헬퍼아카데미(숙박업 학습)
→ 하우스헬퍼(숙소 세팅)
→ 호스트헬퍼(숙소 운영)
→ 라이프헬퍼(외국인 단체 게스트 연결)
→ 넥스트헬퍼(협업·성장)

실제 서비스 라우팅은 직선형 여정만 강제하지 않고, 사용자의 현재 상태에 따라 필요한 브랜드로 바로 연결한다.

## 콘텐츠 운영 원칙
플랫폼 홍보보다 고객의 실제 질문과 지식을 먼저 제공한다.

고객 질문
→ 콘텐츠
→ 체크리스트·워크지
→ 현장 경험
→ 신뢰
→ 상담
→ 플랫폼 이용

최종 목적은 "이 플랫폼을 써봐야겠다" 이전에 "이 분야를 실제로 잘 알고 있구나. 한번 물어보고 싶다"라는 신뢰를 만드는 것이다.

## 공실헬퍼 개발 원칙
공실헬퍼는 일반 부동산 포털이 아니라 "이 숙박 매물을 인수해도 되는가?"를 판단하고 실제 거래 기회까지 연결하는 숙박 매물 거래 플랫폼으로 개발한다.
기능 추가 시 이 역할과 직접 연결되지 않으면 우선순위를 낮춘다.
