# 채널 확장 키트 — 기존 자산 재활용 (제작 0)

기존 릴스/카드뉴스를 유튜브 쇼츠·네이버 블로그에 그대로 올리기 위한 복붙 키트.
새 촬영·새 대본 없이 채널만 늘린다. 계약·수익 단정 금지, "확인 필요" 안전장치 유지.

## 최신 자산 위치 (매일 갱신)
- 릴스: `reel/reel_<prefix>.mp4` (manifest.json의 `prefix`)
- 카드뉴스: `mkt/cardnews/<prefix>_01~06.png`
- 원문 기사: `app.html`의 ARTICLES 최신 항목
- 오늘 편 prefix: `jeongchaek-geojeol` (정책자금 거절 사유 4가지)

## 자동 게시 상태 (주의)
`publish-reel`(인스타·유튜브·스레드)은 `build-reel-daily` 완료를 받아 `workflow_run`으로 실행됩니다.

**이전 기록 정정.** 여기에는 원인이 `[skip ci]` 하나로 적혀 있었으나 **불완전했습니다.** 실제로는 두 가지가 겹쳐 있었고, 실행 이력상 `publish-reel`은 **한 번도 발화한 적이 없습니다**(빌드는 15회 성공).

1. 합성 커밋 메시지의 `[skip ci]`
2. **`GITHUB_TOKEN`으로 푸시한 커밋은 `push` 워크플로를 트리거하지 않는다** — GitHub Actions 규칙(`workflow_dispatch`·`repository_dispatch`만 예외)

`[skip ci]`만 지웠다면 2번 때문에 여전히 돌지 않았을 것입니다. 그래서 트리거를 `workflow_run`으로 바꾸고 `[skip ci]`도 함께 제거했습니다. 새 시크릿은 필요 없습니다.

**아직 검증되지 않았습니다.** `workflow_run`은 기본 브랜치에 있는 워크플로 파일만 트리거하므로, main 병합 후 `reel/daily/manifest.json`을 한 번 갱신해 연쇄가 실제로 도는지 Actions 로그로 확인해야 합니다.

**초록색 = 게시 완료가 아닙니다.** 채널 토큰이 없으면 각 채널을 조용히 건너뛰고 성공으로 끝납니다. 판정은 텔레그램 알림의 채널별 상태로 하세요.

## 1) 유튜브 쇼츠 (최신 reel_<prefix>.mp4 그대로 업로드)
- 제목 템플릿: `<기사 핵심> — 창업 전 꼭 확인`
- 오늘 편 제목: 정책자금, 거절되는 흔한 이유 4가지
- 설명(복붙):
```
정책자금 거절, 대부분 이 4가지에서 걸립니다.
상환 능력·서류·신용도·재신청까지 3분 정리.

창업 매물·상권 정보는 프로필 링크에서.
상담·매칭은 무료입니다.

#창업 #정책자금 #소상공인대출 #점포양수도 #자영업 #쇼츠
```
- 공개설정: 처음엔 비공개(private)로 올려 화질·자막 확인 후 공개.

## 2) 네이버 블로그 (기사 재활용 — SEO 유입)
- 원문: 사이트 최신 기사 본문 복붙(오늘: "소상공인 정책자금, 거절되는 흔한 이유 4가지").
- 제목(검색 최적화): 소상공인 정책자금 거절 사유 — 신청 전 확인할 4가지와 재도전법
- 태그: 소상공인정책자금, 정책자금거절, 점포양수도, 창업준비, 자영업창업
- 하단 CTA: "무료 권리금 진단·상권 리포트는 창업정보 모임에서 받으실 수 있어요" + 사이트 링크(`?utm_source=blog`).
- 이미지: `mkt/cardnews/<prefix>_01~06.png` 6장 삽입.

## 3) 발행 순서 (권장)
인스타 릴스 → 유튜브 쇼츠(같은 mp4) → 네이버 블로그(기사+카드뉴스) → 스레드 요약.
한 번 만든 자산을 4곳에 재사용해 노출을 4배로. 채널별 링크에 `utm_source`를 달아 유입을 구분한다(`instagram`/`youtube`/`blog`/`threads`).
